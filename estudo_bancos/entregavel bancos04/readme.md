# Modelagem Física - PostgreSQL

## Projeto

Banco de dados para gerenciamento de clientes, unidades, salas, reservas e pagamentos.

## Tecnologias

- PostgreSQL
- SQL
- DBeaver
- GitHub

## Implementação

- PK e FK
- NOT NULL
- UNIQUE
- CHECK
- DEFAULT
- Índices
- Transações
- SAVEPOINT
- COMMIT e ROLLBACK
- RETURNING
- EXPLAIN ANALYZE
- ROLE, GRANT e REVOKE

## Segurança

Foi criada uma role de leitura e dois usuários com permissões diferentes, seguindo o princípio do menor privilégio.
